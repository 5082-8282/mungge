# 뭉게뭉게 ☁️

오늘 할 일, 구름처럼 차곡차곡.
14:00 출근부터 17:50 퇴근까지 할 일에 집중하게 도와주는 앱이에요. 할 일을 끝낼 때마다 구름 저금통에 구름이 하나씩 쌓여요.

- 앱 주소: `https://아이디.github.io/mungge/`
- 화면: GitHub Pages
- 저장: 내 구글 시트 (Apps Script)

---

## 1. 구글 시트 저장소 만들기 (처음 한 번만)

1. [sheets.new](https://sheets.new)에서 새 구글 시트를 만들고 이름을 `뭉게뭉게`로 바꿔요.
2. 메뉴에서 **확장 프로그램 → Apps Script**를 눌러요.
3. 열린 화면의 `Code.gs` 내용을 다 지우고, 이 저장소의 [`apps-script/Code.gs`](apps-script/Code.gs)를 통째로 붙여넣어요.
4. 맨 위 줄 `const SECRET = '여기에-비밀번호';`에서 따옴표 안을 **나만 아는 비밀번호**로 바꿔요.
5. 저장(💾)을 누르고, 오른쪽 위 **배포 → 새 배포**를 눌러요.
6. 톱니바퀴에서 **웹 앱**을 고르고 이렇게 맞춰요.
   - 다음 사용자 인증 정보로 실행: **나**
   - 액세스 권한이 있는 사용자: **모든 사용자**
7. **배포**를 누르고 권한을 허용해요. "확인되지 않은 앱" 화면이 나오면 **고급 → (프로젝트 이름)으로 이동**을 눌러요. 내가 만든 코드라서 괜찮아요.
8. 마지막에 나오는 **웹 앱 URL**(`https://script.google.com/macros/s/…/exec`)을 복사해 둬요.

> Code.gs를 나중에 고치면 **배포 → 배포 관리 → ✏️ → 버전: 새 버전 → 배포**를 눌러야 반영돼요. 이때 URL은 그대로예요.

## 2. 앱에 연결하기 (기기마다 한 번씩)

1. 앱 주소를 열어요.
2. **구글 시트 연결하기** 화면에 웹 앱 URL과 비밀번호를 넣고 **연결하기**를 눌러요.
3. 노트북과 폰에서 똑같이 한 번씩 하면, 두 기기가 같은 할 일을 보여줘요. 다른 기기에서 바꾼 내용은 30초마다 불러와요.

## 3. 앱처럼 설치하기

- **아이폰:** 사파리로 앱 주소를 열고 **공유 → 홈 화면에 추가**를 눌러요. 알림은 홈 화면에 추가한 앱에서만 떠요.
- **안드로이드:** 크롬으로 열고 **⋮ → 홈 화면에 추가(앱 설치)**를 눌러요.
- **노트북(크롬/엣지):** 주소창 오른쪽의 설치 아이콘을 누르면 따로 창으로 열 수 있어요.

## 4. 알림

메일·결재 카드의 **알림 켜기**를 누르면 소리와 브라우저 알림이 켜져요.

- 30분마다 샘플실 메일·결재 확인 알림
- 17:40 샘플 대여 결제, 17:46 마감 메일, 17:50 퇴근 알림 (월요일엔 퇴근 문자 예약도 같이)

앱이 열려 있을 때만 울려요. 탭을 닫으면 알림도 안 와요.

## 5. 아이폰 위젯 (Scriptable)

1. App Store에서 무료 앱 **Scriptable**을 설치해요.
2. 아이폰에서 뭉게뭉게 앱을 열고 **설정 → 아이폰 위젯 → 위젯 코드 복사**를 눌러요. 구글 시트 주소와 비밀번호가 들어간 코드가 복사돼요.
3. Scriptable을 열고 오른쪽 위 **+**를 눌러 붙여넣어요. 위쪽 제목을 `뭉게뭉게`로 바꾸고 **완료**를 눌러요.
4. 홈 화면 빈 곳을 길게 누르고 왼쪽 위 **편집 → 위젯 추가 → Scriptable**에서 크기(작게·중간·크게)를 골라 추가해요.
5. 추가한 위젯을 길게 누르고 **위젯 편집 → Script**에서 `뭉게뭉게`를 골라요.

위젯에는 퇴근까지 남은 시간, 오늘 모은 구름 병, 1순위 하나, 끝낸 개수(2/7), 카테고리별 남은 개수가 나와요. 누르면 앱이 열려요. 남은 시간은 계속 줄어들고, 나머지는 보통 15분쯤마다 새로 불러와요(아이폰이 시간을 조절해요).
코드는 [`widget/mungge-widget.js`](widget/mungge-widget.js)에 있어요.

## 파일

| 파일 | 하는 일 |
| --- | --- |
| `index.html` | 앱 화면 전부 |
| `apps-script/Code.gs` | 구글 시트에 저장하고 불러오는 코드 |
| `manifest.webmanifest`, `icons/` | 홈 화면에 설치할 때 쓰는 이름과 아이콘 |
| `sw.js` | 앱을 빨리 열고 알림을 띄우는 서비스 워커 |
| `widget/mungge-widget.js` | 아이폰 Scriptable 위젯 |

비밀번호와 웹 앱 URL은 저장소에 들어가지 않고 각 기기에만 저장돼요.
